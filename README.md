### 💀 What is this?
Most resume checkers are boring. This one is savage.

**Resume Kaand** is an AI tool that:
- **ROASTS** your cringe, generic resume lines
- **SCORES** your ATS compatibility (0-100)
- **FIXES** it with high-impact, number-driven bullets

No more "hardworking and passionate" BS.

### ✨ Features
- 🔥 Brutal AI Roast (English Version)
- 📊 Instant ATS Score with Reason
- ✅ Fixed Version with Action Verbs + Metrics
- 🌑 Premium Dark UI - Built for Devs
- ⚡ Single File - No Backend Needed

### 🛠️ Tech Stack
- HTML5 + Premium CSS
- Vanilla JavaScript
- Google Gemini 1.5 Flash API

### 📦 How to Run Locally
1. Clone the repo
   `git clone https://github.com/tanishqdamse48-png/resumekhaand.git`
2. Rename file to `index.html` (Important!)
3. Just open `index.html` in browser
4. Add your Gemini API Key in the script tag
